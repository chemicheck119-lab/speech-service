# 교차지역 STT 평가 계획

기준일: 2026-09-05

## 목표

광주 화재 신고음성에서 고정한 `faster-whisper small·CPU int8` 설정이 서울·인천 화재
신고음성에서도 물질 관련 정보를 안전하게 보존하는지 평가하고, 그 결과로 Whisper LoRA
실행 여부를 결정합니다.

## 해결하려는 실패 사례와 가설

- 실패 사례: 광주 한 지역에서 선택한 설정이 다른 지역의 신고 음성에서 크게 악화되거나
  존재하지 않는 우선용어를 삽입함
- 가설: hotword를 사용하지 않는 기준선은 지역이 달라도 false insertion을 낮게 유지하지만,
  CER·WER와 물질 관련 표현 회수에는 지역별 차이가 나타날 수 있음

## 기준선과 데이터 분리

- 광주 Training 659건: 향후 학습·개발 전용
- 광주 Validation 77건: 이미 관찰된 내부 고정 비교셋
- 서울·인천 화재 Validation: 교차지역 외부평가 후보, 학습·튜닝 금지
- 실제 무전 음성: 없음

AIHub 다운로드 목록에서 확인한 선택 대상은 서울 화재 Validation 음성 약 645MB·라벨 약
2MB, 인천 화재 Validation 음성 약 93MB·라벨 약 221KB입니다. 실제 레코드 수·음성시간과
해시는 다운로드 후 manifest 검사 결과만 사용합니다.

## 지표

- CER·WER·RTF
- 우선용어 presence Precision·Recall·F1·false insertion
- 후속 단계에서 참조 전사 Parser 물질 언급의 정확 표면명 보존율
- 후속 단계에서 참조 전사 Resolver 후보의 Top-1·Top-3 보존율
- 가설의 자동 CAS 검색 힌트가 참조 후보와 불일치한 횟수
- 확인 전 후보 승격·위험 출력·Rule 실행 위반 건수

AIHub 음성 라벨에는 사람이 확인한 CAS 정답이 없습니다. 따라서 후단 지표는 같은 고정
Parser·Resolver로 참조 전사문과 STT 가설을 각각 분석한 **실버 보존 지표**입니다. 이를
Parser 사람 정답 Recall, Resolver CAS Top-1·Top-3 정확도, 실제 오답 CAS 확정 건수로
표현하지 않습니다.

지역별 발화 구성과 우선용어 출현량이 다르므로 광주와의 단순 점수 차이만으로 채택하지
않습니다. 레코드별 분포·bootstrap 구간과 반복 오류 유형을 함께 봅니다.

## 사전 등록한 해석 기준

- 평가 유효성: 전체 고정 레코드 평가, STT 실패 0건, 설정·archive·manifest 해시 일치
- 처리 가능성: 각 지역 RTF 0.5 이하
- 우선용어 안전성: 각 지역 Precision 0.95 이상, term-negative 기회 대비 false insertion
  비율 0.01 이하
- 후단 안전성: 평가 가능한 모든 전사에서 2-CAS Gate 우회·후보 자동 승격·확인 전 위험
  출력·Rule 조기 실행이 각각 0건
- LoRA 검토 신호: 서로 독립된 두 지역 또는 두 왜곡 조건에서 우선용어 Recall 0.80 미만이나
  참조 후보 Top-3 보존율 0.90 미만의 같은 오류 유형이 반복되고, 해당 지표의 분모가 20개
  이상일 때

CER·WER는 지역별 신고 길이와 표현 구성이 달라 단독 합격선으로 사용하지 않습니다. LoRA
검토 신호가 생겨도 즉시 채택하지 않고 광주 Training 내부 dev에서만 학습·선택한 뒤,
서울·인천을 수정하지 않은 외부평가로 다시 확인합니다.

## 단계 게이트

1. 두 지역 archive의 무결성·스키마·중복 검사를 통과해야 평가를 실행합니다.
2. 광주에서 고정한 설정과 우선용어 목록을 서울·인천 결과를 보기 전에 변경하지 않습니다.
3. false insertion, 참조 불일치 CAS 검색 힌트 또는 확인 전 안전 계약 위반이 생기면 LoRA
   채택 근거로 사용하지 않습니다.
4. 두 지역에서 반복되는 오류 유형이 확인될 때만 광주 Training 기반 LoRA를 실행합니다.
5. LoRA는 서울·인천 외부평가에서 기준선보다 우선용어 F1과 참조 후보 Top-3 보존율을
   개선하고 안전 지표를 유지할 때만 채택합니다. 실제 CAS 정확도 채택 조건은 별도 CAS
   정답 라벨이 생기기 전에는 평가할 수 없습니다.

## 비용과 중단 조건

- 선택 다운로드: 약 740MB(웹 목록 표시값 기준, 다운로드 후 실제 byte 재기록)
- 저장: 비공개 GCS, 원본·전사문·가중치 Git 커밋 금지
- 추론: 기존 Cloud Run Job의 4 vCPU·8GiB 구성을 재사용하되 baseline만 실행
- 실행 상한: 지역별 실제 음성시간 확인 후 설정하며 재시도 0 유지
- 추가 비용이 누적 70,000원 한도를 넘을 가능성이 있으면 실행 전 중단

## 주장 경계

말할 수 있는 것:

- AIHub 서울·인천 화재 신고접수 전화에서의 교차지역 오프라인 성능
- 고정 설정의 지역별 오류와 우선용어 오삽입
- 향후 모의 통신 왜곡에 대한 강건성 실험

말할 수 없는 것:

- 실제 현장 무전 정확도
- 화학시설 신고만의 성능
- 전국 소방본부 일반화
- STT 출력만으로 확인된 CAS 또는 현장 안전성
